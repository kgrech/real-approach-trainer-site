# Real Approach Trainer website

Permanent public website, privacy policy and support information for Real Approach Trainer.

Plain HTML and CSS. No dependencies, build step, JavaScript, analytics or cookies.

## Pages

- Landing: https://kgrech.github.io/real-approach-trainer-site/
- Privacy: https://kgrech.github.io/real-approach-trainer-site/privacy/
- Support: https://kgrech.github.io/real-approach-trainer-site/support/

GitHub Pages publishes the repository root from `main`. Edit the HTML files and shared `styles.css`, commit and push to update the site. Keep application source, internal documentation and credentials out of this repository.

For a local preview, run `python3 -m http.server 8000` in this directory.
